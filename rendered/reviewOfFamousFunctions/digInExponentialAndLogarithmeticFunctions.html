Funções exponenciais e logarítmicas sob uma nova luz.

As funções exponenciais e logarítmicas podem parecer um tanto esotéricas à primeira vista, mas elas modelam muitos fenômenos do mundo real.

1 O que são funções exponenciais e logarítmicas?

Uma função exponencial é uma função da forma \[ f(x) = b^x \] em que \(b\neq 1\) é um número real positivo. O domínio de uma função exponencial é \((-\infty ,\infty )\).
\(b^{-x}\) é uma função exponencial?
sim não
Observe que \[ b^{-x} = \left (b^{-1}\right )^x = \left (\frac {1}{b}\right )^x. \]
Uma função logarítmica é uma função definida da seguinte forma \[ \log _b(x) = y \qquad \text {significa que}\qquad b^y = x \] em que \(b\ne 1\) é um número real positivo. O domínio de uma função logarítmica é \((0,\infty )\).

Em ambas as definições acima, \(b\) é chamado de base.

Lembre-se de que, no caso das funções exponenciais e logarítmicas, existe uma base muito especial: \[ e = 2.7182818284590\ldots \] Esse é um número irracional que você verá com frequência. A exponencial de base \(e\), \(f(x) = e^x\), costuma ser chamada de função ‘exponencial natural’. Para o logaritmo de base \(e\), temos uma notação especial: \(\ln (x)\) é a função ‘logaritmo natural’.

1.1 Conexões entre funções exponenciais e logaritmos

Seja \(b\) um número real positivo com \(b\ne 1\).

  • \(b^{\log _b(x)} = x\) para todo \(x\) positivo
  • \(\log _b(b^x) = x\) para todo \(x\) real

3 Propriedades das funções exponenciais e dos logaritmos

Trabalhar com funções exponenciais e logarítmicas muitas vezes fica mais simples quando aplicamos as propriedades dessas funções. Essas propriedades vão aparecer ao longo de todo o nosso trabalho.

3.1 Propriedades dos expoentes

Seja \(b\) um número real positivo com \(b\neq 1\).

  • \(b^m\cdot b^n = b^{m+n}\)
  • \(b^{-1} = \frac {1}{b}\)
  • \(\left (b^m\right )^n = b^{mn}\)

3.2 Propriedades dos logaritmos

Seja \(b\) um número real positivo com \(b\neq 1\).

  • \(\log _b(m\cdot n) = \log _b(m) + \log _b(n)\)
  • \(\log _b(m^n) = n\cdot \log _b(m)\)
  • \(\log _b\left (\frac {1}{m}\right ) = \log _b(m^{-1}) = -\log _b(m)\)
  • \(\log _a(m) = \frac {\log _b(m)}{\log _b(a)}\)
