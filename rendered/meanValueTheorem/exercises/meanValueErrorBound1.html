Considere a função \(f(x) = \sqrt {x}\).

A aproximação linear de \(f\) em \(a=4\) é \[ L(x) = \class{xm-answer}{\cssId{xm-answer-1}{\phantom{\rule{7em}{1.5em}}}}. \]

Usamos isso para aproximar \(\sqrt {4.1}\) por \[ \sqrt {4.1} \approx 2 + \frac {1}{\class{xm-answer}{\cssId{xm-answer-2}{\phantom{\rule{7em}{1.5em}}}}}. \]

Agora vamos usar o teorema do valor médio para obter cotas superior e inferior rigorosas para o valor de \(\sqrt {4.1}\). Aplicando o teorema do valor médio a \(f\) no intervalo \([4,4.1]\), obtemos \[ \frac {f\left (\class{xm-answer}{\cssId{xm-answer-3}{\phantom{\rule{7em}{1.5em}}}}\right ) - f(4)}{\class{xm-answer}{\cssId{xm-answer-4}{\phantom{\rule{7em}{1.5em}}}}} = f'(c) \] para algum \(\class{xm-answer}{\cssId{xm-answer-5}{\phantom{\rule{7em}{1.5em}}}}<c<\class{xm-answer}{\cssId{xm-answer-6}{\phantom{\rule{7em}{1.5em}}}}\). Podemos isolar \(f(4.1) = \sqrt {4.1}\) na expressão acima, o que nos dá \[ \sqrt {4.1} = \frac {f'(c)}{\class{xm-answer}{\cssId{xm-answer-7}{\phantom{\rule{7em}{1.5em}}}}} + \class{xm-answer}{\cssId{xm-answer-8}{\phantom{\rule{7em}{1.5em}}}}. \]

Agora sabemos que \(f'\) é crescentedecrescente, então, como \(4<c<9\),

\(f'(4)<f'(c)<f'(9)\). \(f'(9)<f'(c)<f'(4)\).
Usamos essas cotas para concluir que \[ 2+\frac {1}{\class{xm-answer}{\cssId{xm-answer-9}{\phantom{\rule{7em}{1.5em}}}}} < \sqrt {4.1} < 2+\frac {1}{\class{xm-answer}{\cssId{xm-answer-10}{\phantom{\rule{7em}{1.5em}}}}}. \] Assim, nossa estimativa obtida pela aproximação linear de \(f\) pode errar por no máximo \(\class{xm-answer}{\cssId{xm-answer-11}{\phantom{\rule{7em}{1.5em}}}}\).
