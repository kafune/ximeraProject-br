Calcule o limite. Escreva ‘DNE’ se o limite não existir e não for nem \(\infty \) nem \(-\infty \). \[\lim _{x \to -\infty } x^5e^{2x} = \class{xm-answer}{\cssId{xm-answer-1}{\phantom{\rule{7em}{1.5em}}}}.\]

xmhintEste é um problema de regra de L’Hôpital, com a forma indeterminada \(-\infty \cdot 0.\)
xmhintPara verificar a forma, note que \(\displaystyle \lim _{x\to -\infty } x^5 = -\infty \) e \(\displaystyle \lim _{x\to -\infty } e^{2x} = e^{-2\infty } = 0\). Isso significa que este limite tem a forma \(0\cdot \infty \). Reescrevendo e aplicando L’Hôpital, temos: \begin{align*} \lim _{x\to -\infty } x^5e^{2x} &= \lim _{x\to -\infty } \frac {x^5}{e^{-2x}} \left (\text {Forma} \, \frac {\infty }{\infty }\right )\\ &= \lim _{x\to -\infty } \frac {5x^4}{-2e^{-2x}} \left (\text {Forma} \, \frac {\infty }{\infty }\right )\\ &= \lim _{x\to -\infty } \frac {20x^3}{4e^{-2x}} = \lim _{x\to -\infty } \frac {5x^3}{e^{-2x}} \left (\text {Forma}\, \frac {\infty }{\infty }\right )\\ &= \lim _{x\to -\infty } \frac {15x^2}{-2e^{-2x}} \left (\text {Forma}\, \frac {\infty }{\infty }\right )\\ &= \lim _{x\to -\infty } \frac {30x}{4e^{-2x}}= \lim _{x\to -\infty } \frac {15x}{2e^{-2x}} \left (\text {Forma}\, \frac {\infty }{\infty }\right )\\ &= \lim _{x\to -\infty } \frac {15}{4e^{-2x}} = \lim _{x\to -\infty } \frac {15}{4}e^{2x} = 0 \end{align*}
