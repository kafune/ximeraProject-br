Estime a área sob a curva \(y=\sin ^2(x)\) entre \(x=0\) e \(x=\pi \) usando \(n=3\) retângulos e tomando os pontos médios como pontos amostrais.
xmhintEste é um cálculo de soma de Riemann com um número pequeno de retângulos. Escreva os intervalos e os pontos amostrais e, em seguida, calcule.
xmhintEstamos calculando uma soma de Riemann com \(\Delta x = \frac {\pi }{3}\) no intervalo \([0,\pi ]\). Portanto, os subintervalos são: \[[0,\pi /3], [\pi /3,2\pi /3], [2\pi /3,\pi ].\] Os pontos médios desses subintervalos são \(x_1^* = \dfrac {\pi }{6}\), \(x_2^* = \dfrac {\pi }{2}\) e \(x_3^* = \dfrac {5\pi }{6}\). A soma de Riemann é: \begin{align*} f(x_1^*)\Delta x + f(x_2^*)\Delta x + f(x_3^*)\Delta x &= \sin ^2\left (x_1^*\right ) \Delta x + \sin ^2\left (x_2^*\right ) \Delta x + \sin ^2\left (x_3^*\right ) \Delta x\\ &= \sin ^2\left (\dfrac {\pi }{6}\right ) \dfrac {\pi }{3} + \sin ^2\left (\dfrac {\pi }{2}\right ) \dfrac {\pi }{3} + \sin ^2\left (\dfrac {5\pi }{6}\right ) \dfrac {\pi }{3}\\ &= \left ( \dfrac {1}{2}\right )^2 \dfrac {\pi }{3} + \left ( 1\right )^2 \dfrac {\pi }{3} + \left ( -\dfrac {1}{2}\right )^2 \dfrac {\pi }{3}\\ &= \dfrac {\pi }{3}\left ( \dfrac {1}{4} + 1 + \dfrac {1}{4} \right ) \end{align*}
\(1\) \(\frac {2}{3}\) \(\frac {\pi }{2}\) \(0\) \(\frac {4}{3}\)
