Seja \(f\) uma função injetora e \(f^{-1}\) sua inversa. Se o ponto \((4,3)\) está no gráfico de \(f^{-1}\), então o ponto \((3,4)\) está no gráfico de \(f\).

Verdadeiro Falso
O gráfico de \(f^{-1}\) contém todos os pontos da forma \(\left (b,f^{-1}(b)\right )\), enquanto o gráfico de \(f\) contém todos os pontos da forma \(\left (f^{-1}(b),f(f^{-1}(b))\right )=\left (f^{-1}(b),b\right )\).
Se \(f\) e \(g\) são duas funções definidas em \(\left (-1,1\right )\) e se \(g(0) = 0\), então necessariamente \(\displaystyle \lim _{x\to 0}\left [f(x)g(x)\right ]=0\).
Verdadeiro Falso
Se \(g(x) = x\) e \(f(x)=\begin{cases} \frac {1}{x} \,; & \text { para } x\neq 0 \\ 0 \,; & \text { para } x=0 \end{cases}\), então \[ \lim _{x\to 0}\left [f(x)g(x)\right ] = 1. \]
Se \(f\) é contínua em \(\left (-1,1\right )\) e se \(f(0) = 10\) e \(\displaystyle \lim _{x\to 0}g(x) = 2\), então \(\displaystyle \lim _{x\to 0}\frac {f(x)}{g(x)} = 5\).
Verdadeiro Falso
Como \(f\) é contínua em 0, sabemos que \(\displaystyle \lim _{x\to 0}f(x) = f(0) = 10\), então podemos usar a lei do limite do quociente para calcular \(\displaystyle \lim _{x\to 0}\frac {f(x)}{g(x)}\).
Seja \(f\) uma função positiva com assíntota vertical \(x=5\); então \(\displaystyle \lim _{x\to 5}f(x) = \infty \).
Verdadeiro Falso
Pode acontecer que \(\displaystyle \lim _{x\to 5^-}f(x) = \infty \), de modo que \(f\) tem uma assíntota vertical em 5, mas \(\lim _{x\to 5^+}f(x)=10\). Nesse caso, \(\lim _{x\to 5}f(x)\) não existe.
