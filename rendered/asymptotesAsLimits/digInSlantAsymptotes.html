Exploramos funções que “disparam para o infinito” em certos pontos de seu domínio.

Se pensarmos em uma assíntota como uma “reta com a qual a função se parece quando a entrada ou a saída é grande”, então há três tipos de assíntotas, assim como há três tipos de retas: \begin{align*} \text {Assíntotas verticais} \qquad &\leftrightarrow \qquad \text {Retas verticais}\\ \text {Assíntotas horizontais}\qquad &\leftrightarrow \qquad \text {Retas horizontais} \\ \text {Assíntotas oblíquas}\qquad &\leftrightarrow \qquad \text {Retas oblíquas} \end{align*}

Aqui criamos um termo novo, reta “oblíqua”, para designar uma reta cuja inclinação não é zero nem é indefinida. Vamos fazer uma rápida revisão dos diferentes tipos de assíntotas:

Assíntotas verticais Lembre-se de que uma função \(f\) tem uma assíntota vertical em \(x=a\) se pelo menos uma das condições a seguir vale:

  • \(\lim _{x\to a} f(x) = \pm \infty \),
  • \(\lim _{x\to a^+} f(x) = \pm \infty \),
  • \(\lim _{x\to a^-} f(x) = \pm \infty \).

Nesse caso, a assíntota é a reta vertical \[ x = a. \]

Assíntotas horizontais Também vimos que uma função \(f\) tem uma assíntota horizontal se \[ \lim _{x\to \infty } f(x) = L \qquad \text {ou}\qquad \lim _{x\to -\infty } f(x) = L, \] e, nesse caso, a assíntota é a reta horizontal \[ \l (x) = L. \]

Assíntotas oblíquas Por outro lado, uma assíntota oblíqua é um bicho um pouco diferente.

Se existe uma reta não horizontal \(\l (x) = m\cdot x+b\) tal que \[ \lim _{x\to \infty }\left (f(x) - \l (x)\right ) = 0 \qquad \text {ou}\qquad \lim _{x\to -\infty } \left ( f(x) - \l (x)\right ) = 0, \] então \(\l \) é uma assíntota oblíqua de \(f\).

Para encontrar assíntotas oblíquas analiticamente, é preciso obter as informações necessárias para determinar uma reta:

  • A inclinação.
  • A interseção com o eixo \(y\).

Embora haja várias maneiras de fazer isso, vamos apresentar um método bastante geral.

Determine a assíntota oblíqua de \[ f(x) = \frac {3x^2+x+2}{x+2}. \]
Queremos saber se existe uma reta \(\l \) tal que \[ \lim _{x\to \infty }\left (f(x) - \l (x)\right ) = 0\qquad \text {ou}\qquad \lim _{x\to -\infty } \left ( f(x) - \l (x)\right ) = 0. \] Primeiro, vamos considerar o limite quando \(x\) tende a mais infinito. Vamos imaginar que temos uma reta assim, \[ \l (x) = m\cdot x + b \] e tentar encontrar os valores corretos de \(m\) e \(b\). Olhemos novamente para o nosso limite. Estamos supondo que: \[ \lim _{x \to \infty } \left (\frac {3x^2 + x + 2}{x+2} - (mx + b) \right ) = 0. \] Sabemos que \(f(x)\) é contínua em todo ponto, exceto em \(x = -2\), e que \(\l (x)\) é contínua em todo ponto, então podemos aplicar nossas leis dos limites longe de \(x = -2\). Estamos olhando para valores grandes de \(x\), então isso não é problema. Usamos o fato de que a soma dos limites é o limite da soma. \begin{align*} \lim _{x \to \infty } \left ( \frac {3x^2 + x + 2}{x+2} \right ) - &\lim _{x\to \infty } (mx+b) = 0 \\ \lim _{x \to \infty } \frac {3x^2 + x + 2}{x+2} = &\lim _{x \to \infty } (mx+b) \end{align*}

Estamos supondo que esses dois limites são iguais. Dividir o lado direito por \(x\) torna o limite igual a \(m\): \begin{align*} m = \lim _{x \to \infty } \left (\frac {mx}{x} + \frac {b}{x}\right ) = \lim _{x \to \infty } \left (\frac {mx+b}{x}\right ). \end{align*}

Para encontrar o valor de \(m\), então, podemos dividir o lado esquerdo por \(x\) e calcular o limite. Obtemos o seguinte. \begin{align*} m &=\lim _{x\to \infty }\frac {\frac {3x^2+x+2}{x+2}}{x}\\ &= \lim _{x\to \infty }\frac {\frac {3x^2+x+2}{x+2}}{x}\\ &= \lim _{x\to \infty }\frac {3x^2+x+2}{x^2+2x}\\ &= \lim _{x\to \infty }\left (\frac {3x^2+x+2}{x^2+2x}\cdot \frac {1/x^2}{1/x^2}\right )\\ &= \lim _{x\to \infty }\frac {3+1/x+2/x^2}{1+2/x}\\ &= \class{xm-given}{3}. \end{align*}

Logo, \(m=3\). Agora sabemos que \[ \lim _{x \to \infty }\frac {3x^2 +x+2}{x+2} = \lim _{x \to \infty } (3x + b) \] para algum valor de \(b\). Para encontrar a interseção com o eixo \(y\), \(b\), usamos um método parecido. Observe que \[ \lim _{x \to \infty }( 3x + b - 3x )= \lim _{x \to \infty } b = b, \] então, se subtrairmos \(3x\) do lado direito, sobra apenas \(b\). Como os dois lados são iguais, subtrair \(3x\) do lado esquerdo e calcular o limite nos dará o valor de \(b\). Escrevemos o seguinte. \begin{align*} b &=\lim _{x\to \infty } \left (\frac {3x^2+x+2}{x+2} - 3x\right )\\ &=\lim _{x\to \infty } \left ( \frac {3x^2+x+2}{x+2} - \frac {3x^2 + 6x}{x+2}\right ) \\ &=\lim _{x\to \infty } \frac {3x^2+x+2-3x^2-6x}{x+2}\\ &=\lim _{x\to \infty } \frac {-5x+2}{x+2}\\ &=\lim _{x\to \infty } \left (\frac {-5x+2}{x+2}\cdot \frac {1/x}{1/x}\right )\\ &=\lim _{x\to \infty } \frac {-5+2/x}{1+2/x}\\ &= \class{xm-given}{-5}. \end{align*}

Por esse método, determinamos que \[ \lim _{x\to \infty }\left (\frac {3x^2+x+2}{x+2} - (3x-5) \right ) = 0. \] Em outras palavras, \(\l (x) = \class{xm-given}{3x-5}\) é uma assíntota oblíqua da nossa função \(f\). Você deve verificar que obtemos a mesma assíntota oblíqua \(\l (x) = \class{xm-given}{3x-5}\) quando tomamos o limite em menos infinito também.
