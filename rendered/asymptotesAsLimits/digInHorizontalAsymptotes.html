Exploramos funções que se comportam como retas horizontais quando a entrada cresce indefinidamente.

Vamos começar com um exemplo:

Considere a função: \[ g(x) = \frac {1}{x} \] com a tabela abaixo \[ \begin{array}{c|c} x & g(x)=\frac {1}{x} \\\hline 10 & \class{xm-given}{0.1} \\ 100 & \class{xm-given}{0.01} \\ 1000 & \class{xm-given}{0.001} \\ 10000 & \class{xm-given}{0.0001} \\ 100000 & \class{xm-given}{0.00001}\end{array} \]

O que a tabela nos diz sobre \(g(x)\) quando \(x\) cresce cada vez mais?

Quando \(x\) cresce cada vez mais, parece que \(g(x)\) se aproxima de \(0\). Parece que deveríamos escrever \[ \lim _{x\to \infty }\frac {1}{x}=0 \]

Agora considere uma função diferente: \[ f(x) = \frac {6x-9}{x-1} \]
Preencha a tabela abaixo, arredondando para \(5\) casas decimais. \[ \begin{array}{c|c} x & f(x)=\frac {6x-9}{x-1} \\ \hline 10 & \class{xm-given}{5.66667}\\ 100 & \class{xm-given}{5.96970}\\ 1000 & \class{xm-given}{5.99700}\\ 10000 & \class{xm-given}{5.99970}\\ 100000 & \class{xm-given}{5.99997}\\ \end{array} \] O que a tabela nos diz sobre \(f(x)\) quando \(x\) cresce cada vez mais?
Quando \(x\) cresce cada vez mais, parece que \(f(x)\) se aproxima de \(6\). Parece que deveríamos escrever \[ \lim _{x\to \infty }\frac {6x-9}{x-1}=6 \]
Se \(f(x)\) fica arbitrariamente próximo de um valor específico \(L\) quando tomamos \(x\) suficientemente grande, escrevemos \[ \lim _{x\to \infty } f(x) = L \] e dizemos que o limite no infinito de \(f(x)\) é \(L\).

Se \(f(x)\) fica arbitrariamente próximo de um valor específico \(L\) quando tomamos \(x\) suficientemente grande e negativo, escrevemos \[ \lim _{x\to -\infty } f(x) = L \] e dizemos que o limite em menos infinito de \(f(x)\) é \(L\).

Calcule o limite. \[ \lim _{x\to \infty } \frac {6x-9}{x-1}. \] Vamos confirmar o que havíamos conjecturado antes calculando o limite no infinito.
Podemos assumir que todas as leis dos limites também valem para limites no infinito.
Escreva \begin{align*} \lim _{x\to \infty }\frac {6x-9}{x-1} &= \lim _{x\to \infty }\frac {6x-9}{x-1}\cdot \frac {1/x}{1/x}\\ &=\lim _{x\to \infty }\frac {\frac {6x}{x} - \frac {9}{x}}{\frac {x}{x} - \frac {1}{x}}\\ &=\frac {\lim _{x\to \infty }\Bigl (6- \frac {9}{x}\Bigr )}{\lim _{x\to \infty }\Bigl (1- \frac {1}{x}\Bigr )}\\ &=\frac {6-9\lim _{x\to \infty } \frac {1}{x}}{1-\lim _{x\to \infty } \frac {1}{x}}\\ &=\frac {6-9(0)}{1-0}\\ &= \frac {6}{1}\\ &= 6. \end{align*}

Observe que, no primeiro passo desse cálculo, dividimos o numerador e o denominador por \(x\) (multiplicando-os por \(1/x\)). Este é um “truque” que frequentemente ajuda no cálculo de limites quando \(x\to \pm \infty \), se a função é uma fração. O ponto importante ao usar \(x\) aqui é que o denominador tem grau \(1\). Quando dividimos o denominador por \(x\), o denominador se aproxima de uma constante não nula. (Estamos dividindo o numerador e o denominador pelo tipo de termo de maior ordem de crescimento do denominador.)

Às vezes é preciso ter cuidado ao tentar aplicar esse truque. Considere este exemplo de uma função não racional.

\[ \lim _{x\to -\infty } \frac {x^3+1}{\sqrt {x^6+5}} \]

O truque que aplicamos acima à função racional vai funcionar aqui, mas observe que o denominador está dentro de um radical. Para determinar o fator correto pelo qual dividir, precisaremos reescrever o radical.

\begin{align*} \sqrt {x^6 + 5} &= \sqrt { x^6\left (\dfrac {x^6}{x^6} + \dfrac {5}{x^6}\right )}\\ &= \sqrt { x^6\left ( 1 + \dfrac {5}{x^6}\right ) }\\ &= \sqrt {x^6} \sqrt {1 + \dfrac {5}{x^6} }\\ &= \sqrt {(x^3)^2} \sqrt {1 + \dfrac {5}{x^6} }\\ &= |x^3|\sqrt {1 + \dfrac {5}{x^6} }\\ \end{align*}

Para este último passo, lembre-se de que \(\sqrt {a^2} = |a|\) quando \(a\) pode assumir um valor negativo. Como estamos olhando para \(x\to -\infty \), sabemos que, a partir de certo ponto, \(x\) será negativo, e \(x^3\) também.

Essa simplificação significa que o denominador, no limite quando \(x\to -\infty \), vai se comportar como \(-x^3\sqrt {1+\dfrac {5}{x^6}}\). Como o fator com a raiz quadrada aqui tem limite \(\displaystyle \lim _{x\to -\infty } \sqrt {1 + \dfrac {5}{x^6} } = \sqrt {1 + \lim _{x\to \infty } \dfrac {5}{x^6}} = \sqrt {1+0}=1\), o crescimento do denominador é controlado pelo fator \(-x^3\). Nesse caso, dividimos o numerador e o denominador por \(x^3\),

\begin{align*} \lim _{x\to -\infty } \dfrac {x^3+1}{\sqrt {x^6+5}} &= \lim _{x\to -\infty } \frac {x^3+1}{-x^3 \sqrt {1 + \dfrac {5}{x^6} }} \cdot \frac {1/x^3}{1/x^3}\\ &= \lim _{x\to -\infty } \dfrac {1+\dfrac {1}{x^3}}{\dfrac {-x^3}{x^3}\cdot \sqrt {1+\dfrac {5}{x^6}}}\\ &= \lim _{x\to -\infty } \dfrac {1+\dfrac {1}{x^3}}{-1\cdot \sqrt {1+\dfrac {5}{x^6}}} \\ &= \dfrac { \lim _{x\to -\infty }\left (1+\dfrac {1}{x^3}\right )}{\lim _{x\to -\infty }-1\cdot \sqrt {1+\dfrac {5}{x^6}}}\\ &= \dfrac {1}{-1\cdot 1} = -1. \end{align*}

No exemplo anterior, usamos o fato de que \(|x^3|= -x^3\) quando \(x\) é negativo. Se o limite fosse quando \(x\to \infty \), então \(x\) e \(x^3\) acabariam assumindo valores positivos. Isso teria resultado em \(|x^3|=x^3\). Repita o cálculo do exemplo anterior, determinando o limite \(\displaystyle \lim _{x\to \infty } \frac {x^3+1}{\sqrt {x^6+5}}\) e tomando o cuidado de usar \(|x^3|=x^3\) na simplificação. Você vai descobrir que os dois limites (quando \(x\to \infty \) e quando \(x \to -\infty \)) têm valores diferentes.

Observe que, como \[ \lim _{x\to \infty } f(x) = \lim _{x\to 0^+} f\left (\frac {1}{x}\right ) \] e \[ \lim _{x\to -\infty } f(x) = \lim _{x\to 0^-} f\left (\frac {1}{x}\right ) \] também podemos aplicar o teorema do confronto ao calcular limites no infinito. Aqui está um exemplo de limite no infinito que usa o teorema do confronto e mostra que as funções podem, de fato, cruzar suas assíntotas horizontais.

Calcule: \[ \lim _{x\to \infty } \frac {\sin (7x)+4x}{x} \]
Podemos limitar nossa função: \[ \frac {-1+4x}{x} \le \frac {\sin (7x)+4x}{x} \le \frac {1+4x}{x}. \] Agora escreva comigo \begin{align*} \lim _{x\to \infty }\frac {-1+4x}{x} \cdot \frac {1/x}{1/x} &= \lim _{x\to \infty }\frac {-1/x+4}{1}\\ &=4. \end{align*}

E também temos \begin{align*} \lim _{x\to \infty }\frac {1+4x}{x} \cdot \frac {1/x}{1/x} &= \lim _{x\to \infty }\frac {1/x+4}{1}\\ &=4. \end{align*}

Como \[ \lim _{x\to \infty } \frac {-1+4x}{x} = 4 = \lim _{x\to \infty }\frac {1+4x}{x} \] concluímos, pelo teorema do confronto, que \(\lim _{x\to \infty }\frac {\sin (7x)}{x}+4 = 4\).

Se \[ \lim _{x\to \infty } f(x) = L \qquad \text {ou}\qquad \lim _{x\to -\infty } f(x) = L, \] então a reta \(y=L\) é uma assíntota horizontal de \(f(x)\).
Dê as assíntotas horizontais de \[ f(x) = \frac {6x-9}{x-1} \]
Pelo nosso trabalho anterior, vemos que \(\lim _{x\to \infty } f(x) = 6\) e, examinando com mais cuidado, vemos que \(\lim _{x\to -\infty } f(x) = 6\). Logo, a assíntota horizontal de \(f(x)\) é a reta \(y=6\).

É um equívoco comum pensar que uma função não pode cruzar uma assíntota. Como mostra o próximo exemplo, uma função pode cruzar uma assíntota horizontal e, no exemplo, isso acontece infinitas vezes!

Dê uma assíntota horizontal de \[ f(x) = \frac {\sin (7x)+4x}{x}. \]
Novamente pelo trabalho anterior, vemos que \(\lim _{x\to \infty } f(x) = \class{xm-given}{4}\). Logo, \(y=\class{xm-given}{4}\) é uma assíntota horizontal de \(f(x)\).

Concluímos com um limite infinito no infinito.

Calcule \[ \lim _{x\to \infty } \ln (x) \]
A função \(\ln (x)\) cresce muito lentamente e parece que poderia ter uma assíntota horizontal; veja o gráfico acima. No entanto, se considerarmos a definição do logaritmo natural como a inversa da função exponencial

\(\ln (x) = y\) significa que \(e^y =x\) e que \(x\) é positivo.

vemos que podemos elevar \(e\) a valores cada vez maiores para obter números cada vez maiores. Isso significa que \(\ln (x)\) é ilimitada e, portanto, \(\lim _{x\to \infty }\ln (x)=\infty \).
