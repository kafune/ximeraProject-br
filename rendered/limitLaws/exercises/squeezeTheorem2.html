Sejam \(g(x) = -x^2\) e \(h(x) = 2\left |x-1\right |-1\).

  1. Calcule os limites a seguir.

    1. \(\lim _{x\to 1}g(x) = \class{xm-answer}{\cssId{xm-answer-1}{\phantom{\rule{7em}{1.5em}}}}\)
    2. \(\lim _{x\to 1}h(x)= \class{xm-answer}{\cssId{xm-answer-2}{\phantom{\rule{7em}{1.5em}}}}\)
    3. \(\lim _{x\to 1}\frac {g(x)}{h(x)} = \class{xm-answer}{\cssId{xm-answer-3}{\phantom{\rule{7em}{1.5em}}}}\)
    4. \(\lim _{x\to 1}\frac {h(x)-h(4)}{x-4} = \class{xm-answer}{\cssId{xm-answer-4}{\phantom{\rule{7em}{1.5em}}}}\)

  2. Encontre a expressão de \(h(x)\), se \(x<1\).

    \(h(x)=\class{xm-answer}{\cssId{xm-answer-5}{\phantom{\rule{7em}{1.5em}}}}x +\class{xm-answer}{\cssId{xm-answer-6}{\phantom{\rule{7em}{1.5em}}}}\), se \(x<1\).

  3. Encontre a expressão de \(h(x)\), se \(x\ge 1\).

    \(h(x)=\class{xm-answer}{\cssId{xm-answer-7}{\phantom{\rule{7em}{1.5em}}}}x -3\), se \(x\ge 1\).

  4. Faça a escolha correta.
    A desigualdade dada, \(g(x) \leq h(x)\), é verdadeirafalsa para todos os valores de \(x\).

  5. Seja \(f\) uma função tal que \(g(x) \leq f(x) \leq h(x)\) para todo \(0 < x < 2\).

    Então \(\lim _{x\to 1}f(x) = \class{xm-answer}{\cssId{xm-answer-8}{\phantom{\rule{7em}{1.5em}}}}\), pelas leis dos limitespela continuidadepela lei da diferençapela lei do quocientepelo teorema do confronto.
