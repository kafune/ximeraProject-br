O teorema do confronto nos permite calcular o limite de uma função difícil “espremendo-a” entre duas funções fáceis.

Em matemática, às vezes podemos estudar funções complicadas relacionando-as a funções mais simples. O teorema do confronto nos mostra uma situação em que isso é possível.

Teorema do confronto Suponha que \[ g(x) \leq f(x) \leq h(x) \] para todo \(x\) próximo de \(a\), mas não necessariamente igual a \(a\). Se \[ \lim _{x\to a} g(x) = L = \lim _{x\to a} h(x), \] então \(\lim _{x\to a} f(x) = L\).

Tenha cuidado com a notação ao usar o teorema do confronto. Não existe uma “desigualdade de três lados” envolvendo valores de limites no teorema do confronto. Para usar o teorema do confronto, você calcula os limites das duas funções que estão nas extremidades da desigualdade. Se eles forem iguais, então você conhece o limite da função que está no meio.

Estou pensando em uma função \(f\). Sei que, para todo \(x\), \[ 0 \le f(x) \le x^2. \] Quanto vale \(\lim _{x\to 0} f(x)\)?
\(f(x)\) \(f(0)\) \(0\) impossível dizer
Uma função contínua \(f\) satisfaz a propriedade \(8x-13 \leq f(x) \leq x^2+2x-4\). Quanto vale \(\lim _{x\to 3} f(x)\)?
\[ \lim _{x\to 3} \left (8x-13\right ) = \class{xm-given}{11}.\] \[ \lim _{x\to 3} \left (x^2+2x-4\right ) = \class{xm-given}{11}.\] Então \[\lim _{x\to 3} f(x) = \class{xm-given}{11}.\]
Considere a função \[ f(x) = \begin{cases} \sqrt [5]{x}\sin \left (\frac {1}{x}\right ) & \text {se $x \ne 0$,}\\ 0 & \text {se $x = 0$,} \end{cases} \]
Essa função é contínua em \(x=0\)?
Devemos mostrar que \(\lim _{x\to 0} f(x) = \class{xm-given}{0}\). Primeiro, vamos supor que \(x\ge 0\) e pequeno. Como \[ -1 \le \sin {\left (\frac {1}{x}\right )}\le 1 \]

multiplicando essas desigualdades por \(\sqrt [5]{x} \ge 0\) , obtemos \[ -\sqrt [5]{x} \le \sqrt [5]{x}\sin {\left (\frac {1}{x}\right )} \le \sqrt [5]{x} \] o que pode ser escrito como

\[ -\sqrt [5]{x} \le f(x) \le \sqrt [5]{x}, \] e, portanto, como \[ -\Big |\sqrt [5]{x}\Big | \le f(x) \le \Big |\sqrt [5]{x}\Big |, \]

Agora, vamos supor que \(x\le 0\) e pequeno. Como \[ -1\le \sin {\left (\frac {1}{x}\right )}\le 1 \] multiplicando essas desigualdades por \(\sqrt [5]{x} \le 0\) , obtemos \[ \sqrt [5]{x} \le \sqrt [5]{x}\sin {\left (\frac {1}{x}\right )} \le -\sqrt [5]{x} \] o que pode ser escrito como \[ \sqrt [5]{x} \le f(x) \le -\sqrt [5]{x}. \]

Lembre-se de que \[ \Big |\sqrt [5]{x}\Big | = \begin{cases} -\sqrt [5]{x} & \text {se $x < 0$,}\\ \sqrt [5]{x} & \text {se $x \ge 0$.} \end{cases} \] Portanto, para todos os valores pequenos de x, \[ -\Big |\sqrt [5]{x}\Big | \le f(x) \le \Big |\sqrt [5]{x}\Big |. \]

Como \[ \lim _{x\to 0} \left ( - \Big |\sqrt [5]{x}\Big | \right ) = \class{xm-given}{0} = \lim _{x\to 0}\Big |\sqrt [5]{x}\Big |, \] aplicamos o teorema do confronto e obtemos que

\(\lim _{x\to 0} f(x) = \class{xm-given}{0}\). Logo, \(f(x)\) é contínua.

Aqui vemos como a definição informal de continuidade, segundo a qual você consegue “desenhar o gráfico” sem “tirar o lápis do papel”, difere da definição formal.

Calcule: \[ \lim _{\theta \to 0} \frac {\sin (\theta )}{\theta } \]
Para calcular esse limite, use o teorema do confronto. Primeiro, observe que só precisamos examinar \(\theta \in \left (\frac {-\pi }{2}, \frac {\pi }{2}\right )\) e, por enquanto, vamos supor que \(\theta \) é positivo. Considere os diagramas abaixo:

A partir dos diagramas acima, vemos que \[ \text {Área do triângulo $A$} \le \text {Área do setor} \le \text {Área do triângulo $B$} \] e, calculando essas áreas, encontramos \[ \frac {\cos (\theta )\sin (\theta )}{2} \le \frac {\theta }{2} \le \frac {\tan (\theta )}{2}. \] Multiplicando tudo por \(2\) e lembrando que \(\tan (\theta ) = \frac {\sin (\theta )}{\cos (\theta )}\), obtemos \[ \cos (\theta )\sin (\theta ) \le \theta \le \frac {\sin (\theta )}{\cos (\theta )}. \] Dividindo tudo por \(\sin (\theta )\) e tomando os recíprocos (o que inverte as desigualdades), encontramos \[ \cos (\theta ) \le \frac {\sin (\theta )}{\theta } \le \frac {1}{\cos (\theta )}. \] Observe que \(\cos (-\theta ) = \cos (\theta )\) e \(\frac {\sin (-\theta )}{-\theta } = \frac {\sin (\theta )}{\theta }\), de modo que essas desigualdades valem para todo \(\theta \in \left (\frac {-\pi }{2}, \frac {\pi }{2}\right )\). Além disso, sabemos que \[ \lim _{\theta \to 0}\cos (\theta ) = \class{xm-given}{1} = \lim _{\theta \to 0}\frac {1}{\cos (\theta )}, \] e assim concluímos, pelo teorema do confronto, que \(\lim _{\theta \to 0}\frac {\sin (\theta )}{\theta } = \class{xm-given}{1}\).

Ao resolver um problema com o teorema do confronto, é preciso escrever uma espécie de poema matemático. Você tem que dizer ao seu amigável leitor exatamente quais funções está usando para “espremer” o seu limite.

Calcule: \[ \lim _{x\to 0} \left (\sin (x) e^{\cos \left (\frac {1}{x^3}\right )}\right ) \]
Vamos traçar o gráfico dessa função para ver o que está acontecendo:
Observação: como \[ -1 \le \cos {\left (\frac {1}{x^3}\right )}\le 1, \] segue que \[ e^{-1} \le e^{\cos {\left (\frac {1}{x^3}\right )}}\le e^{1}. \]

Essa observação é muito importante, pois a função \(\sin (x) e^{\cos \left (\frac {1}{x^3}\right )}\) tem dois fatores:

Logo, temos que, quando \(0< x<\pi \), \[ 0 \le \sin (x) e^{\cos \left (\frac {1}{x^3}\right )} \le \sin (x) \class{xm-given}{e} \] e vemos que \[ \lim _{x\to 0^+}0 = \class{xm-given}{0} = \lim _{x\to 0^+} \sin (x) \class{xm-given}{e} \] e assim, pelo teorema do confronto, \[ \lim _{x\to 0^+}\left (\sin (x)e^{\cos \left (\frac {1}{x^3}\right )}\right )=\class{xm-given}{0}. \] De modo análogo, quando \(-\pi <x<0\), \[ \sin (x) \class{xm-given}{e} \le \sin (x) e^{\cos \left (\frac {1}{x^3}\right )} \le 0 \] e assim \[ \lim _{x\to 0^-}\sin (x) \class{xm-given}{e} =\class{xm-given}{0}=\lim _{x\to 0^-}0, \] e, novamente pelo teorema do confronto, \(\lim _{x\to 0^-}\left (\sin (x) e^{\cos \left (\frac {1}{x^3}\right )}\right )=0\). Logo, vemos que \[ \lim _{x\to 0}\left (\sin (x) e^{\cos \left (\frac {1}{x^3}\right )}\right )=\class{xm-given}{0}. \]
